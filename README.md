Entry for the make.fun competition **"Warning Label for Humans: One Line, Big Laugh"**.

`main.py` writes one single-line safety warning label for human beings to
`/output/entry.txt` — 160 characters or fewer, funny first and plausible
second.

Run it:

```sh
python3 main.py
```

The label it writes:

> WARNING: This human will recount a dream in full detail, including the part that made no sense. Nodding is the only approved safety procedure.
